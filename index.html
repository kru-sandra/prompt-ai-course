Prompt ที่ 1 : คิดไอเดียและเขียน Script

ใช้สำหรับให้ AI ช่วยคิดไอเดีย และเขียน Script จากหัวข้อ กลุ่มเป้าหมาย และรูปแบบคลิปที่ต้องการ
AI จะช่วยเปลี่ยนไอเดียคร่าว ๆ ให้กลายเป็น Script ที่พร้อมนำไปสร้าง VDO โดยยังคงแก่นของไอเดียเดิมไว้
PROMPT
ฉันต้องการทำคลิป [ประเภทคลิป] เกี่ยวกับ [หัวข้อ] กลุ่มเป้าหมาย: [ใครคือคนดู] ความยาว: [เช่น 20 วินาที / 30 วินาที / 60 วินาที] รูปแบบการนำเสนอ: [เล่าเรื่อง / ให้ความรู้ / ขายสินค้า / รีวิว / AI Presenter / Series / อื่น ๆ] ภาษา / สไตล์การพูด: [ภาษาไทย / ภาษาอีสาน / เป็นกันเอง / ตลก / จริงจัง / อื่น ๆ] เนื้อเรื่องหรือไอเดียคร่าว ๆ ของฉัน: [เขียนสิ่งที่คิดไว้แบบสั้น ๆ ได้เลย ไม่จำเป็นต้องเรียบเรียงให้ดี] ช่วยนำข้อมูลทั้งหมดนี้ มาคิดและเขียนเป็น Script สำหรับสร้าง VDO ด้วย AI โดยให้คุณช่วย: - เรียบเรียงไอเดียของฉันให้เป็นเรื่องราวที่เข้าใจง่าย - เติมรายละเอียดที่จำเป็นเมื่อข้อมูลยังไม่ครบ - รักษาแก่นของไอเดียเดิมของฉัน - ทำให้เนื้อหาน่าสนใจตั้งแต่ช่วงต้น - ใช้ภาษาที่เหมาะกับกลุ่มเป้าหมาย - บทพูดต้องเป็นภาษาพูดที่เป็นธรรมชาติ - หากมีตัวละครหลายตัว ให้ระบุว่าใครเป็นคนพูด - ควบคุมบทพูดให้เหมาะกับความยาวของคลิป - ไม่ใส่ข้อมูลที่ไม่เกี่ยวข้องกับเรื่อง ยังไม่ต้องแบ่งเป็นฉาก เพราะฉันจะนำ Script ไปแบ่งฉากในขั้นตอนต่อไป

ฉากที่ 1 → เวลา / ภาพ / ตัวละคร / การกระทำ / บทพูด / อารมณ์

ฉากที่ 2 → เวลา / ภาพ / ตัวละคร / การกระทำ / บทพูด / อารมณ์
PROMPT
จาก Script ที่เขียนไว้ ช่วยแบ่ง Script ออกเป็นฉากสำหรับสร้าง VDO ด้วย AI เงื่อนไขสำคัญ: - แต่ละฉากมีความยาวไม่เกิน 10 วินาที - ต้องต่อเนื่องกัน - ห้ามตัดเนื้อหาสำคัญออก - บทพูดของแต่ละฉากต้องเหมาะกับระยะเวลา - ระบุว่าตัวละครใดพูด - ระบุภาพ/เหตุการณ์ที่เกิดขึ้น - ระบุการกระทำของตัวละคร - ระบุอารมณ์ของตัวละคร จัดเป็นรูปแบบ: ฉากที่ 1 เวลา: ภาพ/เหตุการณ์: ตัวละคร: การกระทำ: บทพูด: อารมณ์: ฉากที่ 2 เวลา: ภาพ/เหตุการณ์: ตัวละคร: การกระทำ: บทพูด: อารมณ์:

Character

Prompt ที่ 3 : สร้าง Character Sheet

ใช้สำหรับสร้างรายละเอียดตัวละครจาก Script เพื่อให้สามารถนำตัวละครไปใช้ต่อในทุกฉาก และช่วยรักษาความเหมือนของตัวละคร
Character Sheet ที่มีรายละเอียด ใบหน้า ทรงผม รูปร่าง เสื้อผ้า บุคลิก และลักษณะเด่นของตัวละคร
PROMPT
ช่วยสร้าง Prompt สำหรับสร้าง Character Sheet ของตัวละครจาก Script นี้ โดยระบุรายละเอียด: - อายุ - เพศ - รูปร่าง - ใบหน้า - ทรงผม - เสื้อผ้า - สีเสื้อผ้า - บุคลิก - อารมณ์ - ลักษณะเด่นของตัวละคร ต้องการภาพแบบ Character Sheet ที่เห็นตัวละครเต็มตัว พื้นหลังเรียบ และสามารถนำไปใช้เป็น Character Reference สำหรับสร้างภาพและ VDO ในฉากต่อ ๆ ไปได้ เน้นให้รายละเอียดของตัวละครชัดเจน เพื่อรักษาเอกลักษณ์ของตัวละคร ให้เหมือนกันในทุกฉาก

สร้างภาพ

Prompt ที่ 4 : สร้างภาพตัวละคร

นำ Character Sheet ไปสร้างภาพตัวละคร เพื่อใช้เป็น Character Reference สำหรับสร้าง Storyboard และ VDO
ภาพตัวละครที่มีใบหน้า เสื้อผ้า และเอกลักษณ์สอดคล้องกับ Character Sheet เพื่อใช้เป็น Reference ต่อไป
PROMPT
สร้างภาพตัวละครจาก Character Sheet ที่กำหนด ต้องรักษารายละเอียดของตัวละครให้เหมือนเดิม ได้แก่: - ใบหน้า - ทรงผม - อายุ - รูปร่าง - เสื้อผ้า - สีเสื้อผ้า - บุคลิก - ลักษณะเด่น ให้ตัวละครมีความเหมือนกับ Character Reference อย่างสม่ำเสมอ สร้างภาพคุณภาพสูง รายละเอียดใบหน้าชัดเจน แสงสวย องค์ประกอบเหมาะสำหรับนำไปสร้าง Storyboard และ VDO ด้วย AI
