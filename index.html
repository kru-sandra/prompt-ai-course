Prompt ที่ 1 : คิดไอเดียและเขียน Script

ใช้สำหรับให้ AI ช่วยคิดไอเดีย และเขียน Script จากหัวข้อ กลุ่มเป้าหมาย และรูปแบบคลิปที่ต้องการ
ชื่อคลิป:
“ป้านินทา…แต่คนที่ได้ยินคือเจ้าตัว!” 😂

Concept สั้น ๆ:
ป้าสองคนกำลังนั่งเม้าท์เพื่อนบ้านอย่างเมามัน แต่ไม่รู้ว่าเพื่อนบ้านที่กำลังถูกนินทา ยืนอยู่ข้างหลังมาตลอด จบด้วยมุกหักแบบภาษาอีสาน

ตัวละคร:
- ป้าสมใจ: ป้าขี้เม้าท์ พูดเก่ง มั่นใจว่าสิ่งที่ตัวเองพูดไม่มีใครได้ยิน
- ป้าทอง: เพื่อนนั่งเม้าท์ด้วย แต่เป็นคนรู้ทันและพยายามเตือน
- ป้าน้อย: เพื่อนบ้านที่ถูกนินทา และยืนอยู่ข้างหลังตั้งแต่ต้น

Script:

ป้าสมใจ:
“มึงเห็นบ่…ป้าน้อยบ้านข้าง ๆ นี่น่ะ แต่งโตคือสิไปงานบุญใหญ่ทุกมื้อ!”

ป้าทอง:
“เบา ๆ แน่ป้า เดี๋ยวเขาได้ยิน”

ป้าสมใจ:
“โอ๊ย! สิได้ยินหยัง บ้านเขาอยู่ตั้งไกลปานนั้น!”

ป้าทอง:
“แต่ป้า…ข้างหลังป้าน่ะ…”

ป้าสมใจ:
“หยัง?”

ป้าน้อย:
“เอ้า! บ่ต้องห่วงดอกป้า…ได้ยินทุกคำเลย 😂”

ป้าสมใจ:
“อ้าว! แล้วมายืนหยังอยู่หม่องนี่ล่ะ?!”

ป้าน้อย:
“ก็มาฟังว่า…ป้าสิชมอีหยังข่อยอีก! 😂”
PROMPT
บทบาทของคุณ: คุณคือผู้เชี่ยวชาญด้านการคิด Content และการเขียน Script สำหรับคลิปวิดีโอสั้น โดยเข้าใจการเล่าเรื่อง การสร้าง Hook และการเขียนบทพูดที่เป็นธรรมชาติสำหรับการสร้าง VDO ด้วย AI หน้าที่ของคุณคือ ช่วยฉันเปลี่ยนไอเดียที่มีอยู่ ให้กลายเป็น Script ที่น่าสนใจ เข้าใจง่าย และพร้อมนำไปสร้าง VDO ด้วย AI ฉันต้องการทำคลิป [ประเภทคลิป] เกี่ยวกับ [หัวข้อ] กลุ่มเป้าหมาย: [ใครคือคนดู] ความยาว: [เช่น 20 วินาที / 30 วินาที / 60 วินาที] รูปแบบการนำเสนอ: [เล่าเรื่อง / ให้ความรู้ / ขายสินค้า / รีวิว / AI Presenter / Series / อื่น ๆ] ภาษา / สไตล์การพูด: [ภาษาไทย / ภาษาอีสาน / เป็นกันเอง / ตลก / จริงจัง / อื่น ๆ] เนื้อเรื่องหรือไอเดียคร่าว ๆ ของฉัน: [เขียนสิ่งที่คิดไว้แบบสั้น ๆ ได้เลย ไม่จำเป็นต้องเรียบเรียงให้ดี] ช่วยนำข้อมูลทั้งหมดนี้ มาคิดและเขียนเป็น Script สำหรับสร้าง VDO ด้วย AI โดยให้คุณช่วย: - เรียบเรียงไอเดียของฉันให้เป็นเรื่องราวที่เข้าใจง่าย - เติมรายละเอียดที่จำเป็นเมื่อข้อมูลยังไม่ครบ - รักษาแก่นของไอเดียเดิมของฉัน - ทำให้เนื้อหาน่าสนใจตั้งแต่ช่วงต้น - ใช้ภาษาที่เหมาะกับกลุ่มเป้าหมาย - บทพูดต้องเป็นภาษาพูดที่เป็นธรรมชาติ - หากมีตัวละครหลายตัว ให้ระบุว่าใครเป็นคนพูด - ควบคุมบทพูดให้เหมาะกับความยาวของคลิป - ไม่ใส่ข้อมูลที่ไม่เกี่ยวข้องกับเรื่อง รูปแบบผลลัพธ์: ชื่อคลิป: Concept สั้น ๆ: ตัวละคร: - ตัวละครที่ 1: - ตัวละครที่ 2: (ถ้ามี) Script: ระบุชื่อผู้พูดก่อนบทพูดทุกครั้ง หากเป็นคลิปเล่าเรื่อง ให้มีต้นเรื่อง → เหตุการณ์ → จุดสำคัญ → ตอนจบ หากเป็นคลิปให้ความรู้ ให้เน้นความถูกต้องและอธิบายให้เข้าใจง่าย หากเป็นคลิปขายสินค้า ให้เน้นปัญหา → ความต้องการ → ข้อมูลสินค้า → ประโยชน์ → CTA โดยใช้เฉพาะข้อมูลสินค้าที่ฉันให้ หากเป็นคลิปตลก ให้เน้นสถานการณ์ใกล้ตัว จังหวะมุก และตอนจบที่ชัดเจน หากเป็น Series ให้รักษาความต่อเนื่องของเรื่องและตัวละคร หากเป็น AI Presenter ให้บทพูดเหมาะกับการพูดโดยตัวละคร AI ยังไม่ต้องแบ่งเป็นฉาก เพราะฉันจะนำ Script ไปแบ่งฉากในขั้นตอนต่อไป

ขั้นตอนถัดไป

Prompt ที่ 2 : แยก Script เป็นฉาก

นำ Script ที่ได้มาแบ่งเป็นฉาก สำหรับสร้าง VDO โดยแต่ละฉาก มีความยาวไม่เกิน 10 วินาที
ฉากที่ 1
เวลา: 0–7 วินาที
ภาพ/เหตุการณ์:
หน้าบ้านในชุมชนอีสานช่วงกลางวัน ป้าสมใจและป้าทองนั่งคุยกันอยู่หน้าบ้าน บรรยากาศเหมือนกำลังเม้าท์กันสนุก ๆ

ตัวละคร:
- ป้าสมใจ
- ป้าทอง
การกระทำ:
ป้าสมใจโน้มตัวเข้าไปกระซิบกับป้าทอง พร้อมทำหน้าทะเล้นและชี้ไปทางบ้านข้าง ๆ ส่วนป้าทองมองซ้ายมองขวาอย่างระวัง

บทพูด:
ป้าสมใจ: “มึงเห็นบ่… ป้าน้อยบ้านข้าง ๆ เฮานี่น่ะ แต่งโตคือสิไปงานบุญใหญ่ทุกมื้อแท้!”
ป้าทอง: “เบา ๆ แนป้า เดี๋ยวเพิ่นได้ยิน!”

อารมณ์:
ป้าสมใจเม้าท์อย่างสนุกและมั่นใจ ป้าทองมีสีหน้ากังวล กลัวเจ้าตัวมาได้ยิน

ฉากที่ 2
เวลา: 7–14 วินาที
ภาพ/เหตุการณ์:
มุมกล้องยังต่อเนื่องจากฉากแรก ป้าสมใจยังนั่งเม้าท์อย่างมั่นใจ โดยไม่รู้ว่าป้าน้อยเดินเข้ามาด้านหลังเงียบ ๆ

ตัวละคร:
- ป้าสมใจ
- ป้าทอง
- ป้าน้อย
การกระทำ:
ป้าสมใจหัวเราะเบา ๆ และโบกมือเหมือนไม่มีอะไรต้องกังวล ขณะที่ป้าทองเหลือบมองไปด้านหลัง เห็นป้าน้อยยืนอยู่ จึงทำตาโตและพยายามส่งสัญญาณเตือน

บทพูด:
ป้าสมใจ: “โอ๊ย! สิได้ยินหยัง บ้านเพิ่นอยู่ไกลปานนั่น!”
ป้าทอง: “แต่ป้า… อยู่ข้างหลังป้านั่นน่ะ…”
ป้าสมใจ: “หยัง?”

อารมณ์:
ป้าสมใจมั่นใจและไม่รู้ตัว ป้าทองตกใจและลุ้นสุด ๆ ป้าน้อยยืนเงียบ ๆ สีหน้ารู้ทัน

ฉากที่ 3
เวลา: 14–20 วินาที
ภาพ/เหตุการณ์:
ป้าสมใจค่อย ๆ หันกลับไป แล้วพบป้าน้อยยืนอยู่ด้านหลังแบบประชิดตัว เกิดจังหวะเงียบชั่วครู่ ก่อนป้าน้อยพูดสวนกลับแบบหน้าตาย

ตัวละคร:
- ป้าสมใจ
- ป้าน้อย
- ป้าทอง
การกระทำ:
ป้าสมใจสะดุ้งและตาโต ป้าน้อยยิ้มมุมปาก ก่อนพูดด้วยน้ำเสียงนิ่ง ๆ แล้วปิดท้ายด้วยมุก

บทพูด:
ป้าน้อย: “เอ้า! บ่ต้องห่วงดอกป้า… ข่อยได้ยินทุกคำอยู่เด้อ!”
ป้าสมใจ: “อ้าว! แล้วมายืนหยังอยู่หม่องนี่ล่ะ?!”
ป้าน้อย: “ก็มาฟังอยู่นี่ล่ะ… ว่าเจ้าสิชมอีหยังข่อยอีก! 🤣”

อารมณ์:
ป้าสมใจตกใจจนทำอะไรไม่ถูก ป้าน้อยนิ่ง ๆ แต่แอบขำและรู้ทัน ป้าทองหลุดขำกับสถานการณ์
จังหวะมุก: หลังประโยคสุดท้ายให้เว้นประมาณ 0.5–1 วินาที แล้วค่อยตัดจบ เพื่อให้มุกทำงานเต็มที่ค่ะ
PROMPT
จาก Script ที่เขียนไว้ ช่วยแบ่ง Script ออกเป็นฉากสำหรับสร้าง VDO ด้วย AI เงื่อนไขสำคัญ: - แต่ละฉากมีความยาวไม่เกิน 10 วินาที - ต้องต่อเนื่องกัน - ห้ามตัดเนื้อหาสำคัญออก - บทพูดของแต่ละฉากต้องเหมาะกับระยะเวลา - ระบุว่าตัวละครใดพูด - ระบุภาพ/เหตุการณ์ที่เกิดขึ้น - ระบุการกระทำของตัวละคร - ระบุอารมณ์ของตัวละคร จัดเป็นรูปแบบ: ฉากที่ 1 เวลา: ภาพ/เหตุการณ์: ตัวละคร: การกระทำ: บทพูด: อารมณ์: ฉากที่ 2 เวลา: ภาพ/เหตุการณ์: ตัวละคร: การกระทำ: บทพูด: อารมณ์:

EP.3 • Storyboard

Prompt ที่ 7 : สร้างภาพ Storyboard Sheet

ใช้สำหรับสร้าง Storyboard Sheet ของแต่ละฉาก โดยใช้ Character Sheet และ Script เป็นข้อมูลอ้างอิงหลัก เพื่อเตรียมภาพ Reference สำหรับสร้าง VDO AI
Storyboard Sheet – ฉากที่ 1
ภาพ Storyboard Sheet จำนวน 6 ช่อง แสดงลำดับเหตุการณ์ของฉากที่ 1 ตั้งแต่ 0–7 วินาที พร้อมภาพ การกระทำ อารมณ์ และมุมกล้อง เพื่อใช้เป็น Reference สำหรับสร้าง VDO AI
PROMPT
สร้างภาพ Storyboard Sheet สำหรับฉากที่ [ใส่หมายเลขฉากที่ต้องการ] โดยใช้ Character Sheet ที่ระบุเป็นภาพอ้างอิงหลัก ข้อกำหนด: - ใช้ตัวละครจาก Character Sheet ที่ระบุเท่านั้น - รักษาใบหน้า รูปร่าง อายุ ทรงผม เสื้อผ้า และเอกลักษณ์ของตัวละครให้เหมือนภาพอ้างอิง - ห้ามสร้างหรือเปลี่ยนตัวละครใหม่ - ใช้ Script ของฉากนั้นเป็นข้อมูลหลักในการกำหนดเหตุการณ์ - แสดงลำดับภาพ การกระทำ สีหน้า อารมณ์ ตำแหน่งตัวละคร และมุมกล้องที่จำเป็นต่อการสร้าง VDO - Storyboard ต้องสอดคล้องกับ Script และต่อเนื่องกับฉากก่อนหน้า - จัดเป็น Storyboard Sheet หลายช่องในภาพเดียว - แต่ละช่องต้องแสดงเหตุการณ์สำคัญของฉากอย่างชัดเจน - เน้นความต่อเนื่องของตัวละครและสถานที่ - ไม่เพิ่มเหตุการณ์หรือรายละเอียดที่ขัดกับ Script OUTPUT: สร้างภาพ Storyboard Sheet ของฉากนี้พร้อมใช้เป็น Reference สำหรับสร้าง VDO AI
